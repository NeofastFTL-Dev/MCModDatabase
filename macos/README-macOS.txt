ModDB for macOS (Apple Silicon + Intel)
=======================================

First launch after downloading
------------------------------
1. Unzip this folder.
2. Double-click "Open ModDB.command".
   That clears Apple's quarantine flag and opens ModDB.
   (macOS may ask to allow Terminal / bash once — choose Allow / Open.)

If you prefer not to use the helper
-----------------------------------
- Right-click ModDB.app -> Open, then confirm Open.
- Or, if Sequoia showed "Apple could not verify..." and you clicked Done:
  System Settings -> Privacy & Security -> scroll to Security -> Open Anyway.

Optional
--------
Drag ModDB.app into Applications after the first successful open.

This build is ad-hoc signed, not notarized. A silent Gatekeeper pass
needs an Apple Developer ID and notarization (not included).
